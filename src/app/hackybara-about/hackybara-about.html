What is Hackybara?
Created for the Spring 2026 Full Stack Web Development class brought to you by the Arkansas Coding Academy! This capstone is made to show off the skill of its students (in this case, Jessica Reid)!



Backend
This API allows you to GET, POST, PUT/PATCH, and DELETE its data via Node.js and Express. A MongoDB Database is used to hold data. Javascript runs most of the API's code.



Frontend
Frontend utilities include Angular and Bootstrap! HTML, CSS, and Typescript (Javascript) are all included in this!
